# Kirani — Advanced TKA, Powers, Patterns & Intro Algebra

Teacher version only.

## How to run
1. **Extract the ZIP.**
2. Open the extracted site folder.
3. Open **`index.html`** in a modern browser.
4. No server, internet connection, CDN, external font, npm runtime, or API is required.

## Teacher controls
- **← Back** = previous activity / previous section. Current local progress is preserved.
- **PASS →** = teacher bypass for the current activity.
- A Teacher **PASS does not count as mastery** and does not mark the skipped activity complete.

## Guided ↔ Try Yourself
For paired teaching activities, the **Guided Example remains available beside Try Yourself** on wide screens. On smaller screens the two cards remain in one paired block and stack vertically, so the model stays immediately available while Kirani attempts the parallel problem.

## Lesson flow
Cover → Warming Up → Back to Zoom → Lesson with Miss:
1. Advanced Story & TKA Problem Solving
2. Design & Measurement
3. Powers → Patterns → Mystery Number → Intro Algebra
→ Independent Transfer → Finish

## Offline use
The site runs fully **offline** after extraction. Keep `index.html`, `css/`, `js/`, and `assets/` together in the same relative folder structure.
